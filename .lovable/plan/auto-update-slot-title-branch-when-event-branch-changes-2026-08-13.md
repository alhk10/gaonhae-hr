# Auto-update slot title branch when event branch changes

## Goal

In the `/access` Grading Events settings dialog, changing the event **Branch** field should automatically rewrite the branch name at the start of every slot **Title**, just as changing the event date or start time already rewrites the date/time portion of the title.

## Current state

- `src/components/grading-list/GradingEventsSettingsDialog.tsx` already has `retitleWithDate(title, isoDate)` and `retitleWithTime(title, time)` helpers that rewrite embedded dates/times in slot titles.
- The **Branch** input uses a plain `setForm(f => ({ ...f, branch_id: v }))` update and does not touch slot titles.
- Slot titles generated by the bulk-add dialog follow the format `Branch - DD/MM/YYYY - HH:mm - Belt info`, so the branch name is the leading token.

## Changes

1. **Add a branch rewrite helper**
   - Create `retitleWithBranch(title: string, newBranchName: string, branches: Branch[]): string`.
   - Split the title on ` - `; if the first segment matches any known branch name, replace it with `newBranchName` and rejoin.
   - If the title is empty or the first segment is not a known branch name, return the original title unchanged so custom text is not corrupted.

2. **Wire the Branch input to rewrite slot titles**
   - In the Branch `Select` `onValueChange`, look up the selected branch name from the `branches` list.
   - Update `form.branch_id` and map over `form.slots` applying `retitleWithBranch(s.title, newBranchName, branches)` to each title.
   - This mirrors the existing `setEventDate` pattern.

3. **Handle duplication**
   - When an existing event is duplicated and its branch is then changed, the titles will update from the old branch name (e.g. `Balmoral`) to the new branch name (e.g. `Yishun`).
   - Empty titles or manually edited titles that do not start with a branch name remain untouched.

4. **No schema or API changes**
   - This is a client-side title convenience only; the saved `title` field continues to be sent as-is to `admin_upsert_grading_slot`.

## Verification

- Open `/access` → Grading tab → Events.
- Duplicate an existing event whose slots have titles starting with a branch name, e.g. `Balmoral - 27/09/2026 - 10:40 - Yellow Tip >> Yellow`.
- Change the **Branch** field from `Balmoral` to `Yishun`.
- Confirm every slot title updates to start with `Yishun`, e.g. `Yishun - 27/09/2026 - 10:40 - Yellow Tip >> Yellow`.
- Confirm saving persists the updated titles.
